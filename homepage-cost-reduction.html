ホームページの管理費・保守費は、毎月の金額が小さく見えるぶん、気づかないうちに大きな固定費になりがちです。 更新をほとんどしていないのに、毎月同じ金額を払い続けているケースも少なくありません。

こんなお悩み

こんなお悩みはありませんか？

ひとつでも当てはまるなら、見直しの余地があるかもしれません。

  • 毎月、管理費・保守費を払っているが、内容をうまく説明できない
  • 文章や写真を変えるだけで、そのたびに費用がかかる
  • 更新をお願いしてから反映まで、時間がかかることが多い
  • WordPressの更新やセキュリティが、よくわからず不安
  • サーバーやドメインの契約が、誰の名義・どこで契約か把握できていない
  • 担当者が替わって、契約内容や費用の理由がわからなくなった

しくみ

なぜ、固定費を減らせる可能性があるのか

理由は「ホームページの仕組みを、必要な形までシンプルにするから」です。

よくある構成（WordPressなど）

  • WordPress本体
  • テーマ
  • プラグイン
  • データベース
  • PHP・サーバー設定

守る・更新するものが多く、
保守に手間と費用がかかりやすい

シンプルな構成

  • HTML
  • CSS
  • JavaScript

保守の対象が少なく、
固定費を抑えやすい

1

WordPress固有の保守が、いらなくなる

事業所の紹介が中心のサイトなら、HTML・CSS・JavaScriptを中心としたシンプルな構成で十分なことが多くあります。アップデートやセキュリティ対応といった、WordPress特有の保守負担を減らせます。

2

公開先を、状況に合わせて選べる

特定のサービスに限定しません。現在お使いのレンタルサーバーを引き続き使う方法も含めて、費用と運用のしやすさから、適切な公開環境をご提案します。

3

「何にいくら」かが、はっきりする

診断では、現在の管理費の中身を一緒に整理します。必要なもの・不要なものが見えるので、乗り換えない場合でも、契約を見直すきっかけになります。

向き・不向き

乗り換えに向いているサイト・向かないサイト

すべてのサイトにおすすめできるわけではありません。正直にお伝えします。

○向いているサイト

  • 事業所・サービスの紹介、料金、アクセスなどが中心
  • お知らせやブログの更新が、あまり多くない
  • WordPressの機能をほとんど使っていないのに、毎月の管理費を払っている
  • 問い合わせは、フォームやメール・電話で足りている
  • 契約内容や費用の中身を、一度整理したい

△向かない・対応が難しいケース

  • 会員専用ページ（ログイン機能）があるサイト
  • ネットショップ（EC）・決済機能があるサイト
  • 複雑な予約システムを組み込んでいるサイト
  • データベースを使った検索・自動表示などが多いサイト
  • 記事数が非常に多く、毎日のように更新するサイト

ご利用の流れ

無料診断から乗り換えまで

診断で終わっても大丈夫です。乗り換えるかどうかは、結果を見てからお決めください。

  1. STEP1

    0円診断のご相談

    フォームからご連絡ください。お急ぎでなければ、お気軽にどうぞ。

  2. STEP2

    契約・サイトの確認

    サイトのURL、管理費の請求内容、契約書などを教えていただき、一緒に確認します。

  3. STEP3

    診断結果のご報告

    乗り換えの可否・費用の比較・お見積りをお伝えします。見送りのご判断も大丈夫です。

  4. STEP4

    乗り換えサイトの制作・移行

    現在のサイトを動かしたまま、新しいサイトを準備します。公開前にご確認いただきます。

  5. STEP5

    公開・旧契約の整理

    公開後の表示を確認してから、旧契約の解約手続きや時期をご案内します。公開後のサポートの選び方もこのときにご相談ください。

※旧サイトの解約は、新サイトの公開を確認してから行うのが安心です。契約期間や違約金の有無は、診断のなかで一緒に確認します。

よくあるご質問

よくあるご質問

診断だけでも相談できますか？

はい、診断だけでも大丈夫です。HP維持費削減診断は0円です。診断の結果、今の契約のままの方がお得な場合は、そのままご利用いただくようお伝えします。

必ず安くなりますか？

必ず安くなるとはお約束できません。現在の契約内容・サイトの構成・公開環境によって異なります。診断で費用の比較をお出しし、乗り換えた方がよいか、そのままがよいかを正直にお伝えします。

乗り換えたあと、月額の管理費は必要ですか？

福祉ITパートナーへの月額管理費は必須ではありません。かかる費用は、乗り換え費用（49,500円〜）と、サーバー・ドメインなど公開環境の実費が基本です。

月額管理費がないと、トラブルのときはどうなりますか？

必要なときだけ、スポットサポート（5,500円〜）でご依頼いただけます。表示の不具合、フォームの不具合、公開設定、サーバー・ドメイン関連の確認、軽微な修正や復旧などが対象で、内容を確認してから作業前にお見積りをお出しします。内容によって料金は変わります。

安心サポート（月額4,400円）には何が含まれますか？

定期的な状態確認、軽微な修正、トラブル時の一次確認を想定した、任意のオプションです。24時間365日の監視、無制限の修正、サーバー会社や外部サービス側の障害の補償は含まれません。詳しい内容は、診断のときにご案内します。

WordPressで作られたサイトでも乗り換えられますか？

事業所の紹介や料金、アクセスなどを載せる一般的なサイトであれば、多くの場合ご相談いただけます。会員機能、ネットショップ、複雑な予約システム、データベースを使ったサイトなどは、基本プランでは単純に移行できない場合があります。

ドメイン（URL）やメールアドレスはそのまま使えますか？

多くの場合、現在のドメインはそのまま使えるように進めます。メールアドレスは契約先によって扱いが異なるため、診断の中で影響が出ないかを必ず確認します。

公開先（サーバー）はどこになりますか？

特定のサービスに限定していません。現在お使いのレンタルサーバーを引き続き使う方法も含めて、費用や運用のしやすさから適切な公開環境をご提案します。

乗り換えた後の更新はどうなりますか？

更新の頻度や内容に合わせて、更新方法をご案内します。ご自身で行う方法のほか、更新のご依頼はスポットサポートや安心サポートでご相談いただけます。

今の制作会社との契約はどうすればよいですか？

解約の時期や条件（契約期間・違約金など）は、契約内容によって異なります。診断の際に契約書などを一緒に確認し、新しいサイトの公開を確認してから整理する流れをご案内します。

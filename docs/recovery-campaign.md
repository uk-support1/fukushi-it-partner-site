## 3. 商品設計（提案）

### 提供範囲（15,000円・税込）
- 1ページ（縦長1枚）／ひな型3種から選択（※ひな型は未制作。承認後に作る）／文章・写真・ロゴはお客様支給（画像5点まで）
- スマホ対応、基本の検索設定（タイトル・説明文）、お問い合わせ先（電話・メールのリンク、またはお客様のGoogleフォームへのリンク）
- 無料公開先への公開設定、お持ちの独自ドメインへの接続（1回。作業1時間以内が目安。ドメイン会社の管理画面でお客様が設定を変更できることが条件。反映に数時間〜1日かかることがある）、制作中の修正1回、公開データ一式の引き渡し
- 納期目安：素材がそろってから約14日（既存プランと同じ表記）

### 含まない（別料金・別プラン）
- 2ページ以上、ブログ・お知らせ機能、ロゴ・写真の新規作成、ドメイン取得代行・移管、メール設定、接続のやり直し（2回目以降。スポットサポート5,500円〜/回）、納品後の修正（スポット5,500円〜／回）、予約・会員・ショップ・決済、PHP/WordPressの内容移行（49,500円〜）、旧デザインの完全再現・データ復旧
- 実費：独自ドメインの年額（お客様名義で取得。金額は会社・種類で異なる）。月額管理費は0円、見守りサポートは任意の4,400円/月（既存）

### 元データがない場合
- 完全復元は保証しない。お手元の資料＋ヒアリングで文章を整える。他者の権利物（旧サイトの画像・文章の無断転載）は使わない。
- 相談時に「15,000円の範囲に収まるか」を先に回答し、範囲外は事前見積りと了承後に着手。

### 公開先と維持費
- 候補：Cloudflare Pages（無料枠）／GitHub Pages。
  - GitHub Pages：公式docsで「オンラインのお店・商取引が主目的のサイト」「SaaS」を無料ホスティングで運営することは想定外、サイト1GB・通信100GB/月は目安（ソフトリミット）と確認。**営利の物販・決済サイトには使わない**。
  - Cloudflare Pages：無料枠の上限は検索結果の要約に基づき、公式ページの全文は未確認。
  - どちらも「将来も無料」の保証はない。LPで明記し、公開データ一式を引き渡して引っ越せるようにしている。
- ドメイン年額は、Cloudflare Registrar経由の.comで年1,500円前後という個人ブログの記載があったのみで、公式価格は未確認。LPには金額を書いていない（「年額の実費」）。

# 福祉ITパートナー｜決定事項・変更履歴

この文書は、ChatGPTで相談して決めた内容のうち、**ほかの開発AIに引き継ぐ必要がある確定事項**とその理由を残す場所です。
会話の全文を保存するものではありません。未決定事項は正式決定として記録しません。

## 記録

### 2026-10-24｜AI間の共通情報保管先をGitHubにする

- **決定：** サービス名・現在の料金・提供内容を [service-catalog.md](service-catalog.md) にまとめ、Claude CodeとCodexが参照できるようにする。
- **理由：** ChatGPTで価格や内容を何度も検討した経緯は相談の中に残し、実装担当AIには決定済みの最新版を正確に渡したいため。
- **注意：** ChatGPTのメモリからGitHubへの自動同期ではない。ユーザーが変更を決めたときに、明示的な更新作業が必要。
- **サイト反映：** この時点では公開サイト本体は変更しない。

# ぶひおの記事内表示

固定画像は `assets/images/buhio/` の6枚を使用します。ダウンロード済みのPNGをそのまま保存しており、投稿時に画像生成は行いません。

| ファイル | 用途 |
| --- | --- |
| buhio-01-standing.png | 通常の説明、導入 |
| buhio-02-waving.png | あいさつ、やさしい案内 |
| buhio-03-pointing.png | ポイント解説、注目箇所 |
| buhio-04-jumping.png | 前向きな話題、成功事例、明るい話 |
| buhio-05-surprised.png | 意外な情報、注意喚起、驚き |
| buhio-06-important.png | 重要な注意点、制度変更 |

記事生成のGemini呼び出しに6種類の用途を渡し、本文とともに `buhio.image`、`buhio.alt`、`buhio.comment` を返してもらいます。コメントは20〜60文字で、記事固有の要点や行動を伝えます。選択結果はMarkdownのYAML front matterの `buhio` に保存します。

直近10件の公開記事の見出し・コメントを参照し、文字列の類似判定と独立したGeminiレビューで意味の重複を確認します。通常は生成に加えてレビューを1回行い、問題があれば最大2回まで修正生成します。詳細は `docs/article-editorial.md` を参照してください。コメント未指定の旧記事には本文の具体的な行動文を使用し、共通の励まし文は使いません。

HTML生成時に本文冒頭へ「ぶひおのひとこと」の囲みを1つ表示します。画像は通常128px、480px以下の画面では88px、最大幅32%、高さ自動です。コメントは折り返し、altとコメントはHTMLエスケープします。

画像名が不正・未指定の場合はタイトル、説明文、本文から用途を判定します。制度変更などの重要事項、注意・驚き、成功、ポイント、あいさつの順に判定し、該当しなければ通常の説明を使います。旧記事もHTML再生成時に補完されます。日付や乱数で画像を選びません。

執筆指示では、専門用語の言い換え、福祉の現場への影響、結局何をすればよいかの説明を求めます。最新情報の取得・出典、下書き保存、公開判定、GitHub Pagesのフローは従来のままです。

## お役立ち情報の身振り（2026-11-17〜）

「ぶひおのひとこと」の画像は、ポーズに合わせて CSS でゆっくり動きます（`assets/css/style.css`）。画像そのものは変えていません。`<aside class="buhio-note" data-pose="…">` の `data-pose` は画像名から自動で付きます。

| ポーズ | 動き |
| --- | --- |
| standing | 息をするように小さく上下 |
| waving | 左右にゆらゆら |
| pointing | 指す方向へ少し前に出る |
| jumping | ぴょんと跳ねる |
| surprised | 時々びくっと揺れる |
| important | 札を見せるように時々大きくなる |

閲覧者が端末で「視差効果を減らす（動きを減らす）」を選んでいる場合は止まります。

## 動く部品（ホームページ作成講座で使える身振り）

`docs/buhio-pet/` のスプライトシートから、身振りのある動く画像（アニメーションWebP）を6種類作りました。保存先は `assets/images/buhio/motion/`。講座の原稿で `[BUHIO type="…" motion="…"]` の `motion` に指定します。

| motion | 動き | 向いている場面 |
| --- | --- | --- |
| talking | 口をパクパク（従来からある `buhio-talking.gif`） | 説明・ポイント |
| smile | にこにこ、まばたき | あいさつ、ひとこと |
| waving | 手をふる | あいさつ、はじめに、締め |
| cheer | ばんざいして喜ぶ | できたこと、前向きな話 |
| thinking | あごに手を当てて考える | 「どうする？」の問いかけ、確認 |
| please | 手を合わせてお願い | 準備・依頼のお願い |
| sad | しょんぼり | よくある失敗例、注意 |

動きを減らす設定の閲覧者には、止まった版（`<名前>-still.webp`）を表示します。作り直すときは `python3 scripts/tools/build-buhio-motions.py`（Pillow が必要）。画像の生成AIは使わず、保管済みのスプライトの枠を切り出して並べるだけです。

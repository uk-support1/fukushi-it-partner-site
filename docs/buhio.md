# ぶひおの記事内表示

固定画像は `assets/images/buhio/` の6枚を使用します。ダウンロード済みのPNGをそのまま保存しており、投稿時に画像生成は行いません。

| ファイル | 用途 |
| --- | --- |
| buhio-01-standing.png | 通常の説明、導入 |
| buhio-02-waving.png | あいさつ、やさしい案内 |
| buhio-03-pointing.png | ポイント解説、注目箇所 |
| buhio-04-jumping.png | 前向きな話題、成功事例、明るい話 |
| buhio-05-surprised.png | 意外な情報、注意喚起、驚き |
| buhio-06-important.png | 重要な注意点、制度変更 |

記事生成のGemini呼び出しに6種類の用途を渡し、本文とともに `buhio.image`、`buhio.alt`、`buhio.comment` を返してもらいます。追加のAPI呼び出しはありません。選択結果はMarkdownのYAML front matterの `buhio` に保存します。

HTML生成時に本文冒頭へ「ぶひおのひとこと」の囲みを1つ表示します。画像は通常128px、480px以下の画面では88px、最大幅32%、高さ自動です。コメントは折り返し、altとコメントはHTMLエスケープします。

画像名が不正・未指定の場合はタイトル、説明文、本文から用途を判定します。制度変更などの重要事項、注意・驚き、成功、ポイント、あいさつの順に判定し、該当しなければ通常の説明を使います。旧記事もHTML再生成時に補完されます。日付や乱数で画像を選びません。

執筆指示では、専門用語の言い換え、福祉の現場への影響、結局何をすればよいかの説明を求めます。最新情報の取得・出典、下書き保存、公開判定、GitHub Pagesのフローは従来のままです。

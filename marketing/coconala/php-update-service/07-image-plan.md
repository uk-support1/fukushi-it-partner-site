### この順番にした理由

1. **1〜3枚目で、「自分のための商品」「状況への共感」「作業の全体像」**を見せる。買い手は、最初の数枚で、買うかどうかを決める。
2. **4枚目で、最大の不安「壊れたらどうなるの？」に答える。** 競合の多くは「更新します」だけで、元に戻せることを前面に出していない（`01-competitor-research.md` §4）。**ここが差別化の核**。
3. **5枚目で、報告書の実物のイメージ**を見せる（確認商品と同じ考え方）。
4. **料金（6枚目）は、価値が伝わったあと**に置く。価格は1枚目にも出ているため、分からない状態にはならない。
5. **範囲（7枚目）とログイン情報（8枚目）は、購入前の不安を取り除く最後の押し。** できないことを先に伝える姿勢が、信頼になる。
6. **9枚目（確認と更新の使い分け）は予備。** 説明文の冒頭に同じ案内があり、画像では2つの商品の関係を示せるが、**価格・商品名が変わると直す必要がある**ため、既定では外した。

> 枚数を減らす場合の優先順位：**1・4・6・7**（訴求／不安への答え／料金／範囲）を残し、2・3・5・8を外す。増やす場合は、9を最後に足す。

## 3. 書き出し方と、直す場所

```sh
# リポジトリのルートで（playwright と Chromium が必要。フォントは Google Fonts から読み込むのでネットワークが必要）
node marketing/coconala/images/src/build.js --dir marketing/coconala/php-update-service/images/src
# 「試験価格」のラベルを外した版（価格の入った 01・06・09 だけ）→ images/no-trial/
node marketing/coconala/images/src/build.js --dir marketing/coconala/php-update-service/images/src --no-trial
# 基本価格を差し替えた版（価格の入った 01・06・09 だけ）→ images/price-8000/
node marketing/coconala/images/src/build.js --dir marketing/coconala/php-update-service/images/src --price 8,000
# 番号を指定して1枚だけ
node marketing/coconala/images/src/build.js --dir marketing/coconala/php-update-service/images/src 05
```

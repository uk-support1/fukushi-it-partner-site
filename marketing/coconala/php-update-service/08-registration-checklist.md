## 3. 公開前チェックリスト（公開ボタンを押す前に、人が確認する）

### A. 内容（事実・断定）

- [ ] 説明文冒頭の日付「2026年10月23日時点」を、公開日に直した
- [ ] 事実関係（修正版の番号・CVE・サポート期限）を、`../01-fact-check-php-vulnerability.md` の出典で再確認した
- [ ] **サーバー会社の対応状況**（さくら・KAGOYA など）を、公開日の公式お知らせで再確認し、説明文の「サーバー会社によっては、すでにサーバー側で修正を済ませています」と矛盾しない
- [ ] 「安全です」「必ず」「保証」「完全」などの言い切りがない（出品文は対応済み。画像も確認済み）
- [ ] 「診断」「点検」を、基本プランの呼び名にしていない（「行っていません」の文脈だけ）
- [ ] 自社サイトのURL・連絡先・Googleフォームがない（外部への誘導）。確認商品への案内は、**商品名のみ**
- [ ] 他の事業所・お客様の名前や事例を出していない
- [ ] 「精神保健福祉士」の表記を、ご本人が確認した
- [ ] **対応サーバー会社の名前**を、実際に作業経験のある会社に絞った（`04-server-compat-and-credentials.md` §1-2）

### B. 価格・オプション

- [ ] 基本価格7,000円が選べた（選べなければ、直近の上の金額にして、説明文・オプション・画像を差し替えた）
- [ ] オプションの金額（+4,000／+3,000×4）が選べた。選べない金額は近い金額にして、文・画像を直した
- [ ] **確認商品の「PHP更新作業 +5,000円」オプションの扱い**を決めた（`02-pricing-and-scope.md` §6。外す場合は、確認商品の説明文・オプション・画像の修正）
- [ ] 乗り換えは、購入ボタンではなく「見積り相談」で案内している

### C. 画像

- [ ] 8枚を `01`〜`08` の番号順にアップロードした（予備の `09` は使わない）
- [ ] 価格の入った画像（`01`・`06`）が、出品する金額と一致している
- [ ] 5枚目に「※架空の例です」が入っている。内容が、実際の報告書（`templates/work-report-template.md`）と同じ形である
- [ ] 画像に、個人情報・サイトのURL・連絡先が写っていない
- [ ] サイズ・形式が、出品画面の案内に合っている
- [ ] 下書きのプレビューで、スマホ表示を確認した

### D. 規約・出品基準

- [ ] 出品基準（規約第16条第1項）を、出品画面で確認した
- [ ] 取消事由（誤解を招く情報・外部サイトへのリンク・第三者の権利の侵害。第16条第4項）に当たる記載がない
- [ ] **トークルーム内でのID・パスワードの受け渡しが、規約・ヘルプで許されているか**を確認した（未確認。競合は実施している。サポートへの問い合わせが確実）
- [ ] **キャンセル・返金の仕組み**（出品者からのキャンセル、一部返金、納品後の扱い）を、公式ヘルプで確認し、`05-failure-policy.md` §8 を直した
- [ ] **追加見積り**（作業中の追加作業、不具合の修正）を、ココナラ上でどう出すかを確認した（見積り機能・追加オプションの購入）
- [ ] 他社の出品の文を、そのまま使っていない

### E. 運用の準備

- [ ] **賠償責任保険**（IT業務）の加入を検討した（`05-failure-policy.md` §7）
- [ ] 初回の返信を、24時間以内にできる体制（受付可否は24時間以内に連絡）
- [ ] 同時対応の枠（2件）を決めた
- [ ] 作業用のブラウザープロファイル（パスワードの保存・自動入力をオフ）を用意した
- [ ] お客様の情報の保存先（リポジトリの外）を決めた
- [ ] 臨時ユーザーの作り方の説明画像（WordPressの「ユーザー → 新規追加」）を用意した（**未作成**。注文後にご案内する画像）
- [ ] 公式マニュアルで、**作業するサーバー会社の最新の切り替え手順**を確認した（`04-server-compat-and-credentials.md` §1-3）
- [ ] 実機（自分のテスト用サイト）で、**一度、手順の全体を試した**（バックアップ → 切り替え → 動作確認 → 切り戻し）

### F. 最後

- [ ] 下書きのプレビューを、自分の目で、通して読んだ
- [ ] **公開ボタンは、自分で押す**

## 4. 公開後の運用

| 内容 | 目安 |
| --- | --- |
| 審査 | 公開後に、ココナラが内容を審査し、基準に疑義がある場合などには、事前の通知なく一時停止・削除される場合がある（規約第16条第3項）。通知が来たら、指摘に沿って直す |
| 最初の5件 | 工程ごとの作業時間・切り戻しの有無・追加見積りの理由を記録し、価格・範囲を見直す（`02-pricing-and-scope.md` §8） |
| 日付の更新 | 数週間後に、冒頭の日付とサーバー会社の対応状況を見直す |
| 確認商品との行き来 | どちらの商品から、どちらへ来たかを記録（購入者のメッセージから分かる範囲）し、案内の文言を調整 |
| 見直し | 公開から1〜2週間後に、表示回数・クリック・購入・問い合わせの内容を見て、タイトル・1枚目・冒頭の文を見直す |

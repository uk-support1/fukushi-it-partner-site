## P0 受付（注文から24時間以内）

- [ ] ヒアリング9項目を確認した（URL／サーバー会社／PHPの版／管理画面のID／既存のバックアップ／止まると困る機能／作業時間帯／連絡可能な時間／データ量・ほかに更新したいもの）
- [ ] **受付条件の8項目**を確認した（`../02-pricing-and-scope.md` §2-3）
- [ ] 受付可否を連絡した（受ける／条件つき／受けない）　→ 受けない場合は `../05-failure-policy.md` No.1
- [ ] 臨時アカウントのお願いを送った（WordPress管理者、必要ならFTP）。二段階認証は解除させない
- [ ] 作業日時を決めた

## P1 事前確認（見るだけ）

- [ ] サイトヘルスの版と、サーバー管理画面の設定が一致している
- [ ] PHPを管理しているのは誰か（お客様／サーバー会社）
- [ ] PHP切り替えの画面を確認した。**元の版が選択肢にある（戻せる）**　→ なければ切り替えない
- [ ] WordPress・テーマ・子テーマ・有効なプラグインの一覧（版つき）を、リポジトリ外に記録した
- [ ] 判定：◎対応済み／△更新が必要／！サポート終了／？要確認　→ 更新不要なら `../05-failure-policy.md` No.2
- [ ] サーバー会社の、今回の脆弱性への対応のお知らせ（URLと日付）を確認した
- [ ] 現在のエラーログの様子を記録した（更新後と比較）
- [ ] サイトの容量（10GB以下）

## P2 バックアップ

- [ ] 方法：サーバー会社の機能／ファイル＋DBの書き出し／プラグイン（お客様の了承を得た）
- [ ] 取得日時が作業の直前
- [ ] 容量が、サイトの容量と近い
- [ ] DBの書き出しの**中身を開いて**、投稿・固定ページ・設定が入っていることを確認
- [ ] 保管場所が非公開（外から開けない）。**当方の端末にダウンロードしていない**
- [ ] 復元の方法を確認した
- 保管場所と名前（報告書に書く）：

## P3 互換性の確認

- [ ] テーマの対応PHP（配布元で確認）
- [ ] 各プラグインの対応PHP・最終更新日（配布元で確認）　○／△／×
- [ ] エラーログの警告・非推奨
- [ ] （オプション2）テスト環境で検証した
- [ ] **×がある → 更新しない**（`../05-failure-policy.md` No.3）。△がある → お客様の了承を得た
- [ ] 互換性のための更新が必要（3つまで／お客様の了承／1つずつ／前後の版を記録）
  - 更新したもの：

## P4 PHPの切り替え

- [ ] お客様に「これから切り替えます」と連絡した
- [ ] 現在の設定画面の写真（元の版）を保存した（認証情報が写っていない）
- [ ] **対象のドメインだけ**を変更した（複数ドメインの契約の場合）
- [ ] 反映を待った（ロリポップ！は5〜10分）
- [ ] サイトヘルスで、実際の版を確認した（更新後の版：　　　　）
- [ ] 今回の修正版以上か（8.3系なら8.3.36以上）　→ 以上でない場合：サーバー会社の案内で確認（番号が変わらないことがある）

## P5 動作確認

- [ ] トップ・主なページ（5〜10ページ）
- [ ] スマホの表示
- [ ] 投稿一覧・固定ページ・検索
- [ ] 管理画面へのログイン・ダッシュボード・投稿の編集画面（開くだけ）
- [ ] お問い合わせフォームの送信テスト（お客様の了承・お客様宛て・「テスト」と明記・受信まで）
- [ ] 画像・メディア
- [ ] 止まると困る機能の入口（決済・個人情報の入力はしない）
- [ ] エラーログが更新前より増えていない
- [ ] サイトヘルスのPHPに関する「要対応」
- [ ] 結果：問題なし／軽微な警告／**問題あり → P6**

## P6 切り戻し（不具合が出たとき）

- [ ] 元のPHPの版を選び直した　／　戻した後の表示確認（元と同じ）
- [ ] 原因の切り分け（エラーログのファイル名・パス）
- [ ] お客様に報告（何が起きたか／戻したこと／原因とみられるもの／選択肢／費用）
- [ ] 選択肢が決まるまで、元の版のまま

## P7 報告・後片付け

- [ ] 作業完了報告書を送った（`work-report-template.md`）
- [ ] 作業中に導入したものを削除した（プラグインなど）。報告書に書いた
- [ ] お客様へ：臨時アカウントの削除／パスワードの変更／FTPアカウントの削除／解除した設定を戻す　をお願いした
- [ ] 当方：作業用ブラウザーの履歴・保存情報を削除。認証情報のメモを残していない
- [ ] バックアップを残すか削除するか、お客様に確認した（既定：7日後に削除してよいか）
- [ ] 7日間の見守りを案内した

## P9 中断した場合

- [ ] 元の状態に戻した（PHPの版・導入したもの）

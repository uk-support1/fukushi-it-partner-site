### 1-1. お受けする場合

```

1. WordPressの臨時の管理者ユーザーの作成（作り方は下の画像のとおりです）
2. サーバーの管理画面にログインできることの確認
3. 現在のPHPの版の確認（WordPress管理画面「ツール → サイトヘルス → 情報 → サーバー」）
4. 作業のご希望の日時（アクセスの少ない時間がおすすめです）

ログイン情報は、このメッセージの中だけでお知らせください（メール・添付ファイルは使わないでください）。
二段階認証は、解除しないでください。作業の時間に、確認コードをお知らせいただければ大丈夫です。

## 2. 事前確認の結果

### 2-1. 進める場合

```
【お名前】様

事前確認が終わりました。
・現在のPHP：【8.1.31】
・サーバー会社：【○○】（PHPの版を切り替えられ、元に戻せることを確認しました）
・テーマ・プラグイン：【12】件を確認。新しいPHPで問題が出そうなものは【ありません／○○（要注意）】

これから、バックアップを取ります。
【○月○日 ○時ごろ】に、PHPを【8.3系】に切り替える予定です。切り替えの間、数分間、サイトが表示されなくなることがあります。
```

終了の場合は、キャンセル（ご返金）の手続きをいたします。
```

```

① 該当のプラグインを入れ替える（別途お見積り）

③ 乗り換えを検討する

```

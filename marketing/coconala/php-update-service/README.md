# php-update-service/ — 【PHP脆弱性対策】PHP更新を代行します（ココナラ新商品・独立商品）

**2026年10月23日。公開の準備は完了。ココナラへの登録・公開は、ご本人の手作業です（`10-publish-manual.md`）。** このセッションには、ブラウザ操作の手段がなく、ログイン・追加認証はご本人しか行えないため、**ココナラには、まだ何も登録していません**（商品URLは、まだありません）。サイト本体（`index.html` など）も変更していません。

「確認」までの既存商品（`../`：【PHP脆弱性】サイトが対象か確認します・2,000円）とは別に、**実際にPHPを更新する**独立商品です。商品の役割は、**① 確認＝知る／② 更新代行＝直す（本商品）／③ 乗り換え＝やめる（見積り相談）**です（`09-existing-product-flow.md` §1）。

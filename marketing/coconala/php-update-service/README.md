# php-update-service/ — 【PHP脆弱性対策】PHP更新を代行します（ココナラ新商品・独立商品）

**ご確認用の企画一式です（2026年10月23日）。ココナラへの登録・画像のアップロード・公開は、まだ行っていません。** サイト本体（`index.html` など）も、既存の確認商品のファイルも、変更していません。

「確認」までの既存商品（`../`：【PHP脆弱性】サイトが対象か確認します・2,000円）とは別に、**実際にPHPを更新する**独立商品です。商品の役割は、**① 確認＝知る／② 更新代行＝直す（本商品）／③ 乗り換え＝やめる（見積り相談）**です（`02-pricing-and-scope.md` §1）。

# 05 商品画像の構成案

専門知識のない方が、**見ただけで「自分のことだ」「何をしてくれるのか」「いくらか」「安心できそうか」が分かる**ことを目的に、7枚を作りました。
画像は `images/`（プランA：基本2,000円）と `images/plan-b/`（プランB：基本3,000円。価格の入った2枚だけ）にあります。

**2026年10月23日の方針決定（`03-product-plan.md` §10）に合わせて、最終調整した版です。** 調整した点：①「報告書（PDF）でお届け」を1・3・5枚目に追加（無料の診断との差別化）、②3枚目の「？要確認」に、確認先と問い合わせの文例を渡すことを追加、③4枚目の乗り換えを「見積り相談から」に変更、④5枚目に「見つからなくても大丈夫」と更新の条件を追加、⑤6枚目を「確認する範囲」に作り直し（確認すること／管理権限が必要なもの／お受けしていないこと）。

## 1. 作りの方針

| 方針 | 内容 |
| --- | --- |
| 1枚に1つのメッセージ | 文字は少なく、大きく。専門用語は使わない（「脆弱性」だけは検索される言葉のため残し、すぐ横でやさしく言い換える） |
| 色・記号・文字の3つで伝える | 4段階の判定は、色だけに頼らず、◎△！？の記号と言葉を必ず添える（色の見分けにくい方にも伝わる） |
| ブランドをそろえる | サイトと同じ色（深緑・オレンジ・クリーム）、フォント（Noto Sans JP）、ロゴ、キャラクター「ぶひお」 |
| 不安をあおらない | 2枚目に「すべてのサイトが危険、ではありません。まずは確認から。」と書く。「緊急」「安全点検」「診断」は使わない |
| スマホで読める | 見出し・価格は36px以上、本文は29px以上。注記・出典・ロゴ帯だけ22〜28px。幅360pxに縮小して、見出し・価格・要点が読めることを確認した（注記は縮小すると小さいが、補足なので許容） |

**サイズ：** 1220×1016px（6:5）のPNG。**大事な文字は、左右102pxの余白の内側（中央の幅1016px）に収めています。** 一覧で正方形に切り取られても、読めるようにするためです（メイン画像を正方形に切り取ってみて、見出し・価格が残ることを確認済み）。

> サイズは、出品者のブログの情報（1220×1016pxが見切れにくい、公式推奨は1220×1240pxとするブログもある）にもとづきます。出品画面の案内で、必ず最終確認してください（`02-market-research.md` §3）。

### 依頼内容との対応

| ご依頼 | 画像での扱い |
| --- | --- |
| 緊急性は伝えるが、あおらない | 2枚目：事実（日付・公式の呼びかけ）だけ。「危険、ではありません」を明記 |
| すべてのPHPサイトが危険という表現は避ける | 2枚目：「対象は『PHPで動くサイト』」「HTMLだけのサイトなどは対象外」 |
| 更新作業は事前の互換性確認・バックアップを前提 | 4枚目：更新オプションの内容に「事前バックアップ」。5枚目：「バックアップ → 更新 → 動作確認」 |
| 基本で確認できる範囲と、サーバー管理権限が必要な作業を明確に | 6枚目（専用の1枚）。1枚目・5枚目にも「ログイン情報は不要」 |
| 乗り換えを無理に勧めず、必要な方にだけ／乗り換えは見積り相談で案内 | 4枚目：③を破線で控えめに「必要な方だけ」「『見積り相談』から」。7枚目：「売り込みは、しません」 |
| PHPバージョンが確認できない場合の対応 | 3枚目：「？要確認」＝確認先と問い合わせの文例をお渡し。5枚目：「見つからなくても大丈夫です」。6枚目：「番号が不明なら『？要確認』でご報告」 |
| 診断範囲を明確に | 6枚目（確認すること／お受けしていないこと）。「診断」は、行っていないことの説明（脆弱性診断）以外に使っていない |
| 無料の診断との差別化 | 1・3・5枚目：「報告書（PDF）」。無料の診断は、画像・出品文では触れない（外部誘導の禁止） |
| 49,500円プランとの整合性 | 4枚目：「49,500円〜」「月額管理費なしでも運用できます」「複雑な機能は個別お見積り」。サイトの表記に合わせた |

## 3. 画像の中の事実と、更新のしかた

画像に入っている事実は、`01-fact-check-php-vulnerability.md` と一致しています。

- 「10月21日」「修正版 8.5.12／8.4.27／8.3.36／8.2.35」「出典：PHP公式（2026年10月21日）」
- 状況が変わったときは、`images/src/` の該当する `.html` を直して、書き出し直します。

```sh
# リポジトリのルートで（playwright と Chromium が必要。フォントは Google Fonts から読み込むのでネットワークが必要）
node marketing/coconala/images/src/build.js            # プランA 全7枚 → images/
node marketing/coconala/images/src/build.js --plan-b   # プランB（価格の入った2枚）→ images/plan-b/
node marketing/coconala/images/src/build.js 03         # 番号を指定して、1枚だけ
```

書き出しのたびに、文字のはみ出し・安全範囲（左右の余白）の外に出た文字・下のロゴ帯との重なりを自動で検査し、問題があれば警告を出します。

| 変わること | 直す場所 |
| --- | --- |
| 修正版の番号・サポート期限 | `03-judge.html`（番号の帯）、`02-what-happened.html` |
| 基本価格 | `01-main.html`・`04-plans.html` の `data-basic`（プランB用は `--plan-b` で書き出し） |
| 更新オプション・乗り換えの価格 | `04-plans.html` |
| 「2026年10月21日」などの日付 | `02-what-happened.html` |

## 4. まだ作っていないもの

| もの | 理由 |
| --- | --- |
| 「PHPの番号の見つけ方」ガイド（WordPressの管理画面・各レンタルサーバーの管理画面の画面写真つき） | 実際の画面写真が必要です。各社の管理画面のメニュー名は、公式マニュアルで確認が取れていません（`01-fact-check-php-vulnerability.md` §4）。ご注文後にお渡しする資料として、実画面で作ることをおすすめします。WordPressは「ツール → サイトヘルス → 情報 → サーバー」 |
| ご報告書のサンプル画像 | 作る場合は、架空の例であることを明記します（実際のお客様・ご相談の例は使いません） |
| ココナラの動画 | 今回は静止画のみ |

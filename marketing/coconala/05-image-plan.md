## 2. デザインの考え方

| 項目 | 内容 |
| --- | --- |
| 配色 | 主役は**深緑**（サイトの `--green-900`）。明るい背景は、やや青みのある白（`#f4f7f4`）。**オレンジは差し色**（警告・「更新は必要な方だけ」）。判定の4色（緑・オレンジ・赤茶・青灰）は、アイコンと文字も添えて、色だけに頼らない |
| 流れ | **1枚目と7枚目だけ深緑の背景**にして、最初と最後を締める。2〜6枚目は明るい背景 |
| アイコン | 線画をそろえる（Feather Icons（MIT）の形をもとに、線の太さをそろえた）。`images/src/icons.js` に一式 |
| 文字 | サイトと同じ Noto Sans JP。見出し60〜100px、要点34〜44px、補足27〜29px。最小は注記・ロゴ帯の24〜25px |
| 余白・安全範囲 | **左右102pxの余白の内側**に文字を収める。一覧で正方形に切り取られても読める（1枚目で確認済み） |
| ロゴ | 左下に小さく（深緑の背景では白い台の上）。右下の補足文は、7枚目のみ |
| サイズ | 1220×1016px（6:5）PNG。出品者ブログの情報にもとづくので、出品画面の案内で最終確認（`02-market-research.md` §3） |

## 5. 特に1枚目（トップ画像）

目的は、**一覧で数秒、目に入ったときに「自分のサイトのことかも」と思い、確認だけなら安い（2,000円）と分かること**です。

| 要素 | 前の版 | 今回 | 理由 |
| --- | --- | --- | --- |
| 背景 | クリーム色＋薄緑の丸 | **深緑（中央がわずかに明るい）** | 一覧で目立つ。セキュリティ・注意喚起らしい落ち着き |
| 図 | ぶひお | **サイト（窓）＋警告（オレンジ）＋盾とチェック（白）** | 「サイトの状態を確認する」が、言葉なしで伝わる。白い盾が視線の終点になる |
| 見出し | 黒に近い深緑、サブはオレンジ | **白の大見出し「PHPの脆弱性」＋ 淡いオレンジの問いかけ「うちのサイトは対象？」** | 暗い背景で最も読みやすく、問いかけが目を引く |
| 補足 | 「確認して、／やさしい言葉の報告書でお届けします」（2行） | **「確認して、報告書でお届けします」（1行）** | 無料の診断との差別化（書面の報告書）は残し、短く |
| 安心の点 | 緑の丸いチェック3つ | **線画のチェック3つ（ログイン情報は不要／専門知識は不要／更新は、必要な方だけ）** | 購入のハードルを下げる3点だけ |
| 価格 | オレンジの丸バッジ | **白いカード＋上のオレンジの線**（「確認だけ 2,000円（税込）」） | 落ち着いたまま、価格は一番大きく読める |
| ロゴ | 左下＋右に「売り込みはしません」 | 左下のみ | 要素を減らす |

## 7. ご依頼（企画時）との対応

| ご依頼 | 画像での扱い |
| --- | --- |
| 緊急性は伝えるが、あおらない | 2枚目：事実（日付・「重大」は公式の表現）と「あわてず、まずは確認から。」。1枚目の警告アイコンは小さく、オレンジの差し色にとどめる |
| すべてのPHPサイトが危険という表現は避ける | 2枚目：「対象は『PHPで動くサイト』」「HTMLだけのサイトなどは対象外」 |
| 更新作業は事前の互換性確認・バックアップを前提 | 4枚目：更新オプションに「バックアップ・更新・動作確認」 |
| 基本で確認できる範囲と、管理権限が必要な作業を明確に | 6枚目（確認すること／しないこと）、1・5枚目の「ログイン情報は不要」。権限が必要な更新は、4・5枚目で「オプション」として分ける。詳細は出品文 |
| 乗り換えを無理に勧めず、必要な方にだけ／見積り相談で案内 | 4枚目：③を破線で控えめに「必要な方だけ」「『見積り相談』から」。7枚目：「売り込みは、しません」 |

| 無料の診断との差別化 | 1・3枚目の「報告書」。無料の診断は、画像・出品文では触れない（外部誘導の禁止） |

## 8. 書き出し方と、直す場所

```sh
# リポジトリのルートで（playwright と Chromium が必要。フォントは Google Fonts から読み込むのでネットワークが必要）
node marketing/coconala/images/src/build.js            # プランA 全7枚 → images/
node marketing/coconala/images/src/build.js --plan-b   # プランB（価格の入った2枚）→ images/plan-b/
node marketing/coconala/images/src/build.js 03         # 番号を指定して、1枚だけ
```

書き出しのたびに、文字のはみ出し・安全範囲（左右の余白）の外に出た文字・下のロゴ帯との重なりを自動で検査し、問題があれば警告します。

| 変わること | 直す場所 |
| --- | --- |
| 色・フォント・余白 | `images/src/common.css` |
| アイコンの形 | `images/src/icons.js`（1つずつ差し替え可） |
| 1枚目の図（サイト＋警告＋盾） | `images/src/01-main.html` の `<svg class="hero">` |
| 基本価格 | `01-main.html`・`04-plans.html` の `data-basic`（プランBは `--plan-b` で書き出し） |
| 更新オプション・乗り換えの価格、日付 | `04-plans.html`、`02-what-happened.html` |

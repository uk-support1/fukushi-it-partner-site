## 出品前に、ご確認・ご判断いただきたいこと

詳細は `03-product-plan.md` §10 にあります。特に大事な3つです。

1. **基本2,000円がココナラのカテゴリで選べるか。** 競合の最安は3,000円で、カテゴリの最低価格は確認できませんでした。選べなければ、プランB（3,000円）に切り替えます（画像も用意済み）。
2. **サイトの「0円診断」との役割の重なり。** 0円診断（契約内容・サイトの仕組みの確認）と、ココナラの基本プラン（PHPの確認）が、お客様から見て似ています。役割を分ける案を書きました。
3. **乗り換え（49,500円〜）を、ココナラの購入ボタンにしない案。** 診断のうえの個別見積りという既存の仕組みと、ココナラの手数料22%・価格の刻み値の制約のためです。

出品画面で確認する項目の一覧は `02-market-research.md` §3 にあります。

# 08 ココナラへの登録手順と、必要な情報

2026年10月23日。**ココナラへの出品操作は、まだ行っていません。** この文書は、出品作業の手順書と、公開直前のチェックリストです。画面の項目名は、ココナラの公式ガイド（[出品の流れ](https://coconala.com/pages/guide_sell)）にもとづく想定で、**実際の画面と違う場合は、画面を優先**してください。

## 2. 登録手順（想定）

> 公式ガイドの流れ（出品するサービスの種類 → ステップ1：カテゴリ・タイトル → ステップ2：サービス内容・価格・購入にあたってのお願い → ステップ3：画像 → ステップ4：公開）にもとづきます。**公式ガイドでは、「必要項目を記載したらすぐに公開できます」とあり、下書き保存の仕様と、FAQの欄の有無は確認できていません。出品画面で、最初に「下書き保存」のボタンがあるかを確認してください。**

| 手順 | 画面の項目（想定） | 入力する内容 | 貼り付け元 | 制限・確認 |
| --- | --- | --- | --- | --- |
| 0 | 出品するサービスの種類 | **通常サービス** | — | ビデオチャットは使わない（手数料27.5%のため） |

## 3. 「公開直前の状態」の定義

次がそろった状態を「公開直前」とします。

- 文章（タイトル〜FAQ）が完成している → **完成**（`04-listing-copy.md`）
- 価格・オプションの設計が確定している → **完成**（`07-pricing.md`。出品画面での選択肢の確認のみ残る）
- 納品物（報告書）のテンプレートがある → **完成**（`templates/`）
- 画像が8枚そろっている → **完成**（1・2枚目はChatGPT版を採用済み。3・4枚目は報告書の見本。ファイル番号＝アップロードする順番）
- 出品画面での確認事項が整理されている → **完成**（本書§4・§5）
- 公開の操作は、していない

## 4. 公開前チェックリスト（公開ボタンを押す前に、人が確認する）

### A. 内容（事実・断定）

- [ ] 説明文冒頭の日付「2026年10月23日時点」を、公開日に直した
- [ ] 事実関係（修正版の番号・CVE・公式の呼びかけ）を、`01-fact-check-php-vulnerability.md` の出典で再確認した
- [ ] 「安全です」「必ず」「保証」「完全」などの言い切りがない（出品文は対応済み。画像・ChatGPT版も確認）
- [ ] 「診断」は「行っていません」の文脈だけ。基本プランを「診断」「点検」と呼んでいない
- [ ] 「確認できないこと」を断定していない（判定は「いただいた情報にもとづく」と書いてある）
- [ ] 自社サイトのURL・連絡先・Googleフォームがない（外部への誘導。規約第13条第2項第12号・第27号、第18条第1項第2号）
- [ ] 他の事業所・お客様の名前や事例を出していない
- [ ] 「精神保健福祉士」の表記を、ご本人が確認した

### B. 価格

- [ ] 基本価格：2,000円が選べた（選べなければ3,000円にして、説明文・画像を差し替えた）
- [ ] 有料オプションの金額（+5,000／+1,500／+3,000／+1,000円）が選べた。選べない金額は、近い金額にして、文・画像を直した
- [ ] 乗り換えは、購入ボタンではなく、「見積り相談」で案内している
- [ ] 49,500円の税込・税別を決めた（サイトの表記も確認）

### C. 画像

- [ ] 8枚を、`01`〜`08` の番号順にアップロードした（1・2枚目はChatGPT版。予備の `09` は、使わない）
- [ ] **1・2枚目（ChatGPT版）：** 当方で、誤字・文字化け・断定の語がないことを検証済み（`10-report-sample-verification.md` §2）。**最終的に、ご自身の目で、文字と価格（基本2,000円）を確認した**
- [ ] 3・4枚目（報告書の見本）に、「※架空の例です」「サンプル（架空の例）」が入っている。見本の内容が、実際に納品する報告書（`templates/`）と同じ形である
- [ ] 画像に、個人情報・サイトのURL・連絡先が写っていない
- [ ] サイズ・形式が、出品画面の案内に合っている
- [ ] 下書きのプレビューで、スマホ表示を確認した

### D. 規約・出品基準

- [ ] 出品のたびに確認する出品基準（規約第16条第1項）を、出品画面で確認した
- [ ] 取消事由（誤解を招く情報・外部サイトへのリンク・第三者の権利の侵害。第16条第4項）に当たる記載がない
- [ ] 生成AIの利用：ココナラのガイドラインは、AI生成イラストそのものを納品物とするサービスを禁止（一部カテゴリ）。**サービス画像にAIを使うこと自体の明示義務は、確認できていない**（`09-automation-investigation.md` §4）。必要なら、出品画面の注意書きを確認

### E. 運用の準備

- [ ] 初回の返信を、24時間以内にできる体制
- [ ] 同時対応の枠（3〜5件）を決めた
- [ ] 報告書テンプレートで、サンプルが作れることを確認した（`templates/README.md`）
- [ ] 見積り相談の返信の流れを、確認した（`07-pricing.md` §5）
- [ ] 振込口座が登録されている（本人確認は、振込申請時）

### F. 最後

- [ ] 下書きのプレビューを、自分の目で、通して読んだ
- [ ] **公開ボタンは、自分で押す**

## 5. 公開後の運用

| 内容 | 目安 |
| --- | --- |
| 審査 | **公開後に、ココナラが内容を審査する。基準に疑義がある場合などには、事前の通知なく、一時停止・削除される場合がある**（規約第16条第3項）。通知が来たら、指摘に沿って直す |
| 初回の返信 | 24時間以内 |
| 見直し | 公開から1〜2週間後に、表示回数・クリック・購入・問い合わせの内容を見て、タイトル・1枚目・冒頭の文を見直す |
| 日付の更新 | 数週間後に、冒頭の「2026年10月21日」「○月○日時点」を見直す（`01-fact-check-php-vulnerability.md` を再確認） |
| 実績の記録 | 最初の5件で、作業時間・追加費用の発生・見積りの内容を記録し、`07-pricing.md` の仮の数字を直す |
| サイト側の反映（今回は変更しない） | `assets/js/main.js` の `SITE_CONFIG.coconalaUrl` は、既存出品を指している。新商品へ誘導する場合は、記事・比較ページにリンクを足す変更が別に必要（`03-product-plan.md` §11） |

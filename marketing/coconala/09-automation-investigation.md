# 09 ココナラ出品の自動化（Claude in Chrome／Cowork）の調査

調査日：2026年10月23日。**ココナラのサイトには、一度もアクセスしていません**（出品作業を行わない指示のため。調査は、公式の規約・ヘルプの読み取りと、このセッションの環境確認だけです）。

## 1. 結論

| 項目 | 結論 |
| --- | --- |
| このセッション（クラウド環境）から実行できるか | **できません。** Claude in Chrome のツールも、Cowork の環境も、このセッションにありません（§2）。そのため、**ココナラの画面での動作は、まったく試せていません** |
| 手元のPC（Chrome／Claude Desktop）で、技術的に可能か | **公式ヘルプ上は、可能と考えられます。** 有料プラン＋Chrome＋拡張機能（Coworkなら Claude Desktop）があれば、ページの読み取り・入力・クリックを任せられます。ただし、ココナラの出品画面（独自のカテゴリ選択・価格の選択肢・オプション欄・画像のアップロード）で確実に動くかは**未検証**です |
| ココナラの規約で禁止されているか | **「出品者が自分の出品を作るために、AIのブラウザ操作を使うこと」を名指しで禁じる条項は、確認できた範囲ではありません。** ただし、**ID・パスワードを第三者に使わせることは禁止**（第74条第2項）で、運営を妨げる行為などの一般条項もあります（§4）。規約の解釈は、最終的にはココナラの判断です。続けて使う場合は、ココナラのお問い合わせで確認するのが確実です |
| おすすめ | **今回の1件の出品は、手動の貼り付けを第一にしてください**（所要の目安は30分前後。貼り付け表は `08-registration-guide.md`）。自動化は、試すなら**「下書きの入力まで」に限定**し、公開ボタンは自分で押してください（§6）。1件だけの出品では、設定の手間のほうが大きく、**公開ボタンの押し間違いのリスク**（§5）が、節約できる時間より重いためです |

## 2. このセッションで確認したこと

| 確認 | 結果 |
| --- | --- |
| Claude in Chrome のツール（`mcp__claude-in-chrome__*`、有効化用の `enable__mcp__claude-in-chrome`）が使えるか | **使えません**（検索しても存在しない）。公式ヘルプの説明では、Claude in Chrome は、**利用者本人のChromeが起動していて、拡張機能が接続されているとき**にだけ動きます。このセッションはクラウド上のため、接続できません |
| Cowork の環境があるか | **ありません。** このアカウントの実行環境は、`anthropic_cloud`（「福祉ITパートナー」「てすと」）の2つだけで、Cowork用（`remote_cowork`）はありません |
| ココナラへのアクセス | **していません** |

## 3. 利用に必要な設定（手元のPCで試す場合）

出典は、Claudeの公式ヘルプです（末尾の出典）。

### 3-1. 前提

| 項目 | 内容 |
| --- | --- |
| プラン | **有料プラン**（Pro・Max・Team・Enterprise）。Freeは対象外 |
| ブラウザ | **Google Chrome のみ**（他のChromium系ブラウザ・モバイルは非対応） |
| Claude Desktop | Coworkを使う場合、およびローカルのファイル・コンピューター操作には、**Claude Desktop（macOS／Windows）を開いて接続しておく**必要がある |
| 状態 | Chrome側のサイドパネルは**ベータ版**。画面が表示されない場合は、アプリを最新にするか、管理者（Team／Enterprise）に確認 |

### 3-2. 2つのやり方

| | A. Claude in Chrome（拡張機能） | B. Cowork の内蔵ブラウザ |
| --- | --- | --- |
| 動く場所 | **普段使いのChrome**（開いているタブ・サインイン済みのアカウント） | Claude Desktop に内蔵された**別のブラウザ**。普段のタブ・ログインには触れない |
| ログインのしかた | ココナラに**自分でサインイン**してある状態を使う（Claudeにパスワードを渡さない） | 内蔵ブラウザで**自分でサインイン**する。**サインイン情報は、同じPCの今後のCoworkセッションでも残り、Claudeが使える**（保存済みログインの取り込みは、サイトごとに選べ、銀行・メール等は初期状態でオフ） |
| 向いている場面 | 目の前の画面を見ながら、短い作業を任せる | 別の作業を続けながら、任せておく |
| 今回の出品作業での注意 | **ココナラ専用のChromeプロファイル**を作り、銀行・医療などのアカウントがない状態にする（公式の安全ガイド） | 長く残るログインを避けるため、**作業後にサインアウト**する |

### 3-3. 設定手順（Aの場合）

1. Chrome ウェブストアで、発行元が Anthropic の「Claude」拡張機能を追加し、Claudeアカウントでサインインし、ツールバーにピン留めする。
2. **ココナラ専用のChromeプロファイル**を作る（普段のブラウザと分ける）。
3. そのプロファイルで、**自分で**ココナラにログインする（IDとパスワードは、Claudeに入力させない・教えない）。
4. 権限モードは、**「Manually approve（手動承認）」**にする。1つ1つの操作の前に、許可を求められる。サイトの許可は、**「Allow this action」（1回だけ）**を選び、「Always allow actions on this site」は、このサイトでは選ばない。**「Skip all approvals」は使わない。**
5. Claude Desktop から使う場合：設定 → **Connectors** → **Claude in Chrome** → **Configure** でオンにする。コネクタは、**チャットごとに手動で有効にする**必要がある。Coworkで既定のブラウザを指定する場合は、**Settings → Cowork → Preferred browser** で選ぶ。
6. 指示文は、§7のテンプレートを使う（公開・購入・支払いに関わる操作を明示的に禁止する）。

> Coworkの内蔵ブラウザ（B）を使う場合は、拡張機能のインストールは不要です。Claude Desktop の Settings → Cowork で、既定のブラウザを「Built-in browser」にします。

## 4. ココナラの規約・制限

出典は、ココナラの[利用規約](https://coconala.com/pages/terms_user)（取得した本文の最終改定日：2025年12月19日）です。条文番号は、取得した内容にもとづきます。**法律の解釈は専門家・ココナラ運営の判断によるため、以下は読み取りの結果です。**

| 条文 | 内容 | 今回への影響 |
| --- | --- | --- |
| 第13条第2項第22号 | 「出品者より提供されたサービス・コンテンツ等に対し、自動的に応答する等の機能を有する装置、ソフトウェア、アルゴリズム等を利用する行為」の禁止 | **対象は、他の出品者のサービスに対する自動応答（購入側の自動操作など）**と読めます。**自分の出品を作る作業とは、別の話**に見えます（確認はココナラ運営） |
| 第13条第2項第23号 | 「不当に情報を操作することを目的として利用する行為」の禁止 | 出品情報の入力自体は該当しませんが、**ランキング・評価を操作する目的の自動操作は避ける** |
| 第13条第2項第29号 | 「当社サービスの運営及び当社の業務を妨害する行為」の禁止 | **短時間に大量の操作を繰り返さない。** 1件の出品を、人の速さで入力する範囲に収める |
| 第13条第2項第19号 | 複数のユーザ名・パスワードを利用する行為の禁止 | **1つのアカウントだけ**を使う |
| **第74条第2項** | **ユーザ名・パスワードの、第三者への使用許諾・貸与・譲渡・売買・名義変更などの禁止** | **Claudeに、IDとパスワードを渡さない・入力させない。** 自分がログインした状態で使う |
| 第13条第2項第12号・第27号、第18条第1項第2号、第16条第4項第14号 | 目的と合わない外部サイトへのリンク／直接取引の誘引／連絡先の掲載の禁止。出品内容にそうしたリンクを含むと、出品取消の対象 | 入力する文章に、自社サイトのURL・連絡先・Googleフォームを入れない（出品文は対応済み） |
| 第18条第1項第5号・第16条第4項第12号 | 掲載情報の虚偽表示の禁止。誤解を与える情報を含む出品は、取消の対象 | **自動入力でも、掲載内容の責任は出品者本人。** 「安全です」などの言い切りは使わない（出品文は対応済み） |
| **第16条第3項** | **出品後に、ココナラが内容を審査する。基準に疑義がある場合などには、事前の通知なく、一時停止・削除できる** | 公開後に審査される。**公開前の最終確認は、人が行う** |
| 第16条第1項 | 出品するには、加盟店契約を結び、出品者登録を完了する必要がある | 出品者登録がまだなら、先に済ませる（`08-registration-guide.md`） |
| 第17条第7項ほか | 振込申請時に本人確認。確認が終わるまで振込を留保する場合がある | 公開自体の条件ではないが、**売上の受け取りには本人確認が必要**（`08-registration-guide.md`） |

**生成AIについて：** ココナラの[生成AIガイドライン（2023-12-05）](https://coconala.com/news/917)は、生成AIの活用を支援ツールとして推奨しています。禁止されているのは、**一部のカテゴリで、AI生成のイラストそのものを納品物とするサービス**です。商品説明や画像にAIを使うこと自体や、AI利用の明示義務は、**確認できた範囲では記載がありません**（未確認）。1・2枚目をChatGPTで作る場合も、他者の画像を無断で使っていないこと（第16条第4項第19号、第21条）の確認は、出品者の責任です。

## 5. 操作上の制限・リスク

| # | 内容 | 対策 |
| --- | --- | --- |
| 1 | **公式ガイドでは、「必要項目を記載したらすぐに公開できます」。** 公開ボタンを押すと、審査の前に公開される | 自動操作でも手動でも、**公開は最後に自分が押す。** 指示文で、公開・購入に関わるボタンを禁止する（§7） |
| 2 | 下書き保存の仕様は、公式のガイドでは確認できなかった（出品者のブログでは、「公開する」を押さず「下書き保存」を使うよう推奨されている） | **出品画面で、下書き保存のボタンがあることを、最初に確認する**。なければ、自動化は行わない |
| 3 | 画像のアップロード：公式ヘルプの機能一覧には、「ページの読み取り・クリック・入力・移動・フォーム入力」とあり、**ファイルのアップロードは明記されていない**（ダウンロードと機密情報の入力は、確認が必要な操作） | **画像は、自分でアップロードする**前提にする。1・2枚目はChatGPT版のため、そもそも手元のファイルが必要 |
| 4 | 出品画面の部品（カテゴリの選択、価格の選択肢、有料オプションの追加、文字数カウンター）は、独自の作りで、自動入力が途中で止まる可能性がある | 入力は、**1欄ずつ、画面で確認しながら**。2〜3回失敗したら止める |
| 5 | Claude in Chrome は、ページに隠された指示（プロンプトインジェクション）の影響を受けるリスクが、ゼロではない（公式） | **ココナラの出品画面以外には移動させない。** 想定外の動き（関係ない話題、知らないサイトへの移動）があれば、すぐに止める |
| 6 | 画面の内容が、スクリーンショットとして取り込まれる。サイドパネルのセッションは、履歴に保存され、他の端末からも開ける（公式） | **銀行・個人情報が表示されたページでは、拡張機能を開かない。** ココナラ専用プロファイルを使う |
| 7 | **投稿・送信・購入・データの変更の結果や、第三者サイトの利用規約の遵守は、利用者の責任**（Claudeの公式の安全ガイド） | 規約の確認と、最終の公開は、人が行う |
| 8 | 購入・支払いは、公式の安全ガイドで、確認の対象として明記されていない | **出品作業のあいだは、ポイント・コイン・お支払いに関わる画面に触れさせない**（指示文で禁止） |

## 6. 安全な試験の進め方（手元のPCで試す場合）

| 段階 | 内容 | 操作の範囲 |
| --- | --- | --- |
| 0 | 準備：ココナラ専用プロファイル、拡張機能、手動承認モード（§3-3）。入力用の文章（`08-registration-guide.md` の貼り付け表）を手元に用意 | — |
| 1 | **読み取りだけ：** 自分でログインし、出品画面を開く。Claudeには、**画面の項目名・文字数制限・「下書き保存」の有無を、読み上げさせるだけ**にする（入力・クリックはさせない） | 読み取りのみ |
| 2 | **1欄だけ入力：** 例えばタイトルだけを入力させ、画面で確認する。うまく動くかを見る | 入力（1欄） |
| 3 | **下書きの入力：** 貼り付け表のとおり、順番に入力させる。**1欄ごとに、画面で確認**する | 入力・「下書き保存」のみ |
| 4 | **人が確認して公開：** 下書きのプレビューを、自分の目で確認し、**公開ボタンは自分で押す** | 人が操作 |

**やらせないこと：** 公開、購入、ポイント・コイン・支払いの画面、アカウント設定・本人確認・口座の変更、他人へのメッセージ送信、ログイン、外部サイトへの移動。

## 7. 指示文のテンプレート（下書きの入力まで）

> 次の作業だけを、この順番で行ってください。
> **目的：** ココナラの出品画面（通常サービス）に、下書きとして文章を入力する。
> **やってよいこと：** 画面の項目名と文字数制限を読む／私が示す文章を、指定の欄に入力する／「下書き保存」を押す。
> **やってはいけないこと：** 「公開」「出品する」など、サービスを公開するボタンを押すこと。購入・ポイント・コイン・お支払いに関わる画面に触れること。ログイン・パスワード・本人確認・口座情報の入力。外部サイトへの移動。私が示していない文章の追加・書き換え。
> **進め方：** 1欄ずつ入力し、入力のたびに、画面に表示された内容を私に報告してください。想定外の画面・確認ダイアログ・エラーが出たら、操作せずに止めて、状況を私に伝えてください。同じ操作が2〜3回うまくいかなければ止めてください。
> **最後に：** 「下書き保存」までで終了し、公開はしないでください。公開は私が行います。

## 8. 判断の目安

| | 手動の貼り付け（おすすめ） | 自動化を試す |
| --- | --- | --- |
| 所要時間（目安） | 30分前後 | 設定＋試験で、1時間以上かかる可能性（初回） |
| 規約上の安心 | 高い | 明示の禁止は確認できないが、運営の判断に不確実さが残る |
| 誤公開のリスク | 自分で押す | 指示文・手動承認で抑えるが、ゼロにはならない |
| 向いている場面 | 今回のような**1件の出品** | 同じ形の出品を、**何件も、定期的に**作るとき（その場合は、事前にココナラへ確認を） |

**今後の使い道（現実的なもの）：** 自動入力よりも、**出品前のチェック**（文字数カウンターの確認、文章の見直し、画面の見え方のチェック）や、**公開後の画面での表示確認**を、読み取りだけで頼むほうが、リスクが小さく、効果もあります。

## 9. 未確認

- ココナラの出品画面での、実際の動作（入力・下書き保存・プレビュー）。**試していません。**
- 「下書き保存」ボタンの有無と、公開前の審査の有無（公式ガイドは「すぐに公開できます」としか書かれていない）。
- 画像のアップロードを、Claude in Chrome で行えるか（公式ヘルプの機能一覧に明記なし）。
- 規約の、AI操作に関する解釈（ココナラ運営への確認が必要）。
- Claude in Chrome／Cowork の画面や名称は、ベータ版のため、変わる可能性があります（公式ヘルプでも、旧名称と新名称が混在）。

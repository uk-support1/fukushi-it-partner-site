# ameba-ownd-end-short/ — ショート動画「Ameba Ownd 終了」（特設ページとのタイアップ）

特設ページ（`https://fukushi-it-partner.com/ameba-ownd-end.html`。2026年11月5日時点の公式発表にもとづく）を紹介する、約29秒の縦動画（1080×1920・30fps）です。構成案は `../scripts/ameba-ownd-end-short.md`。**投稿・公開は、していません。**

## できあがり

| ファイル | 内容 |
| --- | --- |
| `ameba-ownd-end-short.mp4` | **BGM＋ナレーションつき**（約29秒） |
| `ameba-ownd-end-short-bgm-only.mp4` | BGMだけ（ナレーションなし）。ナレーションの声が合わない場合に使う |

- **画面**：特設ページのスクリーンショットを切り抜いて貼り（`crops/`）、テロップと「動くぶひお」を重ねています。ページに載っていない情報は入れていません。
- **ぶひお**：`docs/buhio-pet/`（ブランチ `claude/buhio-pet-validation-fdm5m4`）に保管された、動くぶひおのスプライトシートから、**waiting（心配）・idle・running-right（走る）・review（確認）・thinking（考える）・jumping（喜ぶ）・waving（手を振る）**を使っています。場面2だけは、固定画像の「ここ重要！」の看板（`assets/images/buhio/`）です。
- **音**：BGMは、その場で合成した**オリジナル**（既存の曲は使っていません。やさしい音色のオルゴール風）。ナレーションは**合成音声**（Kokoro-82M、日本語。声は `jf_alpha`）。ナレーションの間は、BGMを自動で下げています。音量は、YouTubeの目安（約−14 LUFS）にそろえています。

## 作り直し方（リポジトリのルートで）

```sh
# 1) 特設ページを切り抜く（公開中のページを使う。ページが変わったら、ここからやり直す）
node marketing/youtube/ameba-ownd-end-short/capture.js
# 2) 動くぶひおを切り出す（元の画像は、ブランチ claude/buhio-pet-validation-fdm5m4 の docs/buhio-pet/ から取り出す）
git show origin/claude/buhio-pet-validation-fdm5m4:docs/buhio-pet/spritesheet-atlas.webp > /任意の場所/spritesheet-atlas.webp
python3 -I marketing/youtube/ameba-ownd-end-short/make-sprites.py /任意の場所/spritesheet-atlas.webp
# 3) ナレーションと音（Kokoro-82M と numpy・soundfile が入った Python 3.12 の環境で）
python make-narration.py        # narration.json の文を変えたら、ここから
python make-audio.py
# 4) コマを書き出し、MP4にする
node marketing/youtube/ameba-ownd-end-short/render.js     # frames/ に879枚（約6分）。--still で、場面ごとの静止画だけ
bash marketing/youtube/ameba-ownd-end-short/build.sh
```

画面の文言・秒数・ぶひおの位置は `scenes.json`、ナレーションの文は `narration.json`、見た目は `video.html` です。場面の長さを変えるときは、ナレーションの長さ（`audio/durations.json`）に収まるか、`render.js` の警告で確認できます。

## 確認が必要な点

- **ナレーションの声の質は、私は耳で確認できていません。** 読み方は、音の並び（`check-reading.py`）で確認しました。**「12月24日」を、そのまま書くと「じゅうに・つき」と読まれる誤りがあり**（ご指摘で判明。文字起こしでは見つからなかった）、ひらがなに直しました。ほかの文（数字「一万五千円」、「概要欄」「ドメイン」「移行先」など）は、正しい並びです。**投稿の前に、必ず耳で聞いて**ください。合わなければ、BGMだけの版を使うか、`narration.json` の `voice`・`speed` を変えて作り直します。
- **YouTubeの「変更または合成されたコンテンツ」の申告**が必要かどうかは、投稿時の設問で確認してください（合成音声のナレーションを使っているため。現在の基準は未確認）。
- **動くぶひおの1コマあたりの表示時間**は、元のデータ（`pet.json`）が未保管のため、仮に決めています（歩く・走る：毎秒12コマ、ほかは毎秒6〜8コマ）。
- **解像度**：動くぶひおは、1コマが約168×182pxのため、2倍に拡大して使っています。画面の隅の約330〜430pxの大きさでは、粗さは目立ちませんが、さらに大きくする場合は、元解像度のシートが必要です。
- **概要欄のリンク**：ショートの概要欄の外部リンクが押せるかは、現在の仕様が未確認です（押せない場合は、プロフィールのリンクや固定コメントで案内）。
- 情報が変わったとき（移行期間の延長など）は、動画の中の日付・文言が古くなります。最後の画面に「2026年11月5日時点」を入れています。

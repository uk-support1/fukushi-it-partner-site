# marketing/youtube/ — ショート動画の企画・台本

今後、ショート動画の企画・台本をここに置きます。今回の作業ではココナラ商品の制作を優先したため、まだ中身はありません。

## 置くもの（案）

- `ideas.md`：企画の一覧（テーマ・狙う視聴者・1行の要点）
- `scripts/`：台本（1本1ファイル）

## 参考

- 既存のブログ記事（`content/articles/`）は、動画の元ネタにできます。特に、PHP脆弱性の一連の記事（`critical-php-vulnerability-2026-10` ほか）は、
  ココナラ商品（`../coconala/`）の販促動画にも使えます。
- 動画の説明欄などでココナラ商品を紹介するときも、`../coconala/03-product-plan.md` の「表現のルール」に従ってください。

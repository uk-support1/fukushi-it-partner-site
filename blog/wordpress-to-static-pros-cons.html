WordPressから静的HTMLへ移行するメリット・デメリット｜福祉事業所の場合

PHP・セキュリティ 2026.10.22
ぶひおのひとこと

今のサイトで使っている機能を、一覧にしてみよう。

WordPressで作ったホームページを、PHPを使わない静的なホームページ（静的HTML）に移行する。この選択肢を、PHPの脆弱性のニュースをきっかけに検討する方もいます。ただ、メリットだけでなく、デメリットも知っておくことが大切です。

この記事では、移行のメリットとデメリットを、福祉事業所の視点で正直に整理します。静的サイトのしくみそのものは、PHPを使わないホームページとは？で説明しています。

移行すると、何が変わりますか？

移行前（WordPress） 移行後（静的HTML）
更新するもの WordPress・テーマ・プラグイン・PHP・データベース ファイルと、サーバー・ドメインの契約
文章・写真の更新 管理画面から ファイルの書き換え、または依頼
PHPの脆弱性 更新が必要 対象外
問い合わせフォーム WordPressのプラグインなど 外部のフォームサービスなど

移行のメリット

1. 保守の手間と費用を減らしやすい

WordPress本体・テーマ・プラグイン・PHP・データベースの更新が、必要なくなります。更新の担当者が決まっていない、保守を頼む費用が負担になっている、といった場合は、大きな違いになります。

2. PHPの脆弱性の心配がなくなる

PHPを使わないため、今回のようなPHPの脆弱性の対象にはなりません。更新が遅れて困る、という状況が減ります。

3. 表示が速くなる傾向がある

できあがったファイルをそのまま返すため、アクセスのたびにサーバーでページを作る必要がありません。

4. 更新できないまま古くなる悪循環から抜けられる

古いプラグインやテーマが原因で、PHPを更新できない、という状況からは、解放されます。

5. ランニングコストを抑えやすい

公開に必要なサーバー・ドメインの実費はかかりますが、保守のための月額費用は、必須ではなくなります。

移行のデメリットと、注意したい点

メリットだけでなく、デメリットも知っておくことが大切です。次の点は、移行の前に必ず確認してください。

1. 管理画面での簡単な更新ができなくなる

WordPressのように、管理画面から文章や写真を書き換えることは、基本的にできません。更新は、ファイルの書き換えや、制作会社への依頼になります。更新の頻度が高い事業所には、不向きな場合があります。更新のやり方は、移行の前に必ず相談してください。

2. 機能を置き換える必要がある

問い合わせフォーム、検索機能、コメント機能、予約機能などは、そのままでは動きません。外部のサービスに置き換えるか、機能そのものをやめる判断が必要です。置き換えがむずかしい機能が多いサイトは、移行に向きません。フォームについてはPHPのお問い合わせフォームはどうする？で説明しています。

3. ホームページのアドレス（URL）が変わると、検索に影響が出ることがあります

WordPressのときのアドレスと、移行後のアドレスが違うと、検索結果から来ていた方が見つからなくなる、検索順位が下がる、といった影響が出る可能性があります。今のアドレスをそのまま引き継ぐ、または、古いアドレスから新しいアドレスへ自動的に転送する設定をする、といった対応が必要です。転送の設定ができるかどうかは、公開先のサーバーによって違います。

4. 古いサイトの後片付けが必要

移行したあと、古いWordPressがサーバーに残っていると、PHPが動き続けるため、今回の脆弱性の対象のままです。新しいサイトの公開を確認してから、古いサイトを片付けます。ファイルやデータベースを削除する前には、念のため、バックアップを保管しておきましょう。

5. 初期の費用がかかる

移行のための制作・作業費用がかかります。長く使うほど、保守の費用との差で取り戻せる場合がありますが、すぐに安くなるとは限りません。

福祉事業所の場合に、とくに確認したいこと

  • 問い合わせフォームに、利用者さんやご家族の個人情報が入力される場合、どこにデータが保存されるかを確認する（外部サービスを使う場合は、そのサービスの規約・保管場所）
  • 行政や関係機関への掲載・届出の内容と、ホームページのアドレスが一致しているか確認する（アドレスを変える場合は、関係先への連絡が必要になることがあります）
  • ホームページを更新する人（担当者）を、移行後も決めておく

移行の基本の流れ

  1. 今のホームページを確認します（ページの数、使っている機能、アドレス、サーバー・ドメインの契約）
  2. 残す機能と、やめる機能、置き換える機能を整理します
  3. 新しいサイトを作ります（今のサイトは動かしたままです）
  4. 公開前に、内容と表示を確認します
  5. 公開して、表示とフォームなどの動作を確認します
  6. 新しいサイトの公開を確認してから、古いサイトを片付けます
  7. 更新のしかたや、困ったときの連絡先を決めます

移行しないほうがよいケース

向かないサイトは、無理に移行しないほうがよいです。次のような場合は、PHPとWordPressを更新して使い続けるか、別の方法を検討します。

  • 会員専用ページ（ログイン機能）がある
  • ネットショップ・決済機能がある
  • 複雑な予約システムを組み込んでいる
  • データベースを使った検索や自動表示が多い
  • 記事数が非常に多く、毎日のように更新する

福祉ITパートナーの乗り換えプランの場合

福祉ITパートナーの「ホームページ維持費削減・乗り換えプラン」は、事業所紹介を中心とした小規模なホームページを想定した基本プランで、49,500円〜です（サーバー・ドメインなど公開環境の実費は別です）。福祉ITパートナーへの月額の管理費は、必須ではありません。

ただし、上のような向かないサイトや、PHPで動くフォームなどがある場合は、基本プランでは移行できないことがあります。その場合は、個別にお見積りをご案内するか、現在のまま使うことをおすすめします。プランの詳しい内容は、ホームページ維持費削減・乗り換えプランをご覧ください。

更新を続ける方法も含めた比較は、PHPホームページの更新・乗り換え方法を比較で説明しています。毎月の管理費の見直しについては、ホームページのセキュリティ対策と管理費用の見直し方もご覧ください。
